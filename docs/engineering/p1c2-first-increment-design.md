# P1-C2 first increment, before implementation

2026-10-17. Local native-layout recovery and explicit held capability routes only. No external processing, live inference, production changes or agents.

Reproduction: the P1-C1 real two-column fixture interleaves text in the selected page view and has zero eligible units. Whole-passage agreement in both native candidates fails even when dictionary blocks have intact within-column lines. Reordering bytes alone does not prove clinical relationships.

Add an opt-in local recovery API, leaving default extraction/production processing unchanged. Retain original canonical, cleaned and page-candidate buffers; add a versioned named alternate view, exact source-block mappings, page comparisons and route decisions. Use bounded recursive whitespace cuts to separate columns/bands. Retain all native text blocks; ambiguous geometry, overlap, rotation or incomplete inventory holds a page instead of guessing. Do not repair hyphens, signs, units, ligatures or values.

Record line spans, line boxes/directions and native order. A recovered clinical candidate must still pass existing scope/context gates. Where whole-passage comparison fails because of interleaving, require ordered exact line corroboration from both native extraction families, with native horizontal line geometry inside one source block. Preserve every corroboration span; repeat/ambiguous matches and conflicting values hold. Recompute certificates on generation and load. Local warnings remain visible and document completeness stays blocked.

Use typed page/region routes for native text/layout, table-relationship review, figure review, unclassified visual signals and OCR-required/unavailable. Scanned extraction retains an inspectable evidence result on its existing classified failure; a separate inspection API can report it without claiming usable clinical text. No OCR/vision capability is assumed available or authorized.

Test first: synthetic interleaving recovery, named-buffer round trips, immutable old views, all-block retention, route persistence, OCR-only rejection, ambiguous layouts/line matches/damaged signs, unsupported numeric claims and incomplete coverage. Then select real corpus anchors from recovered eligible candidates, inspect original rendered pages independently of algorithm output, record byte/page/block/span/text hashes in regression metadata, and compare all 30 PDFs. This engineering source check is not clinician approval or a clinically adjudicated benchmark.

Stop after the first verified C2 increment. Keep generation optimization, length-policy changes, durable unit recovery and external services deferred.
